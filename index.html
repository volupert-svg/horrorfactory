horrorfactory

개인용 YouTube Shorts 업로드 도구

horrorfactory는 운영자가 직접 만든 짧은 영상(YouTube Shorts)을 운영자 본인의 YouTube 채널에 비공개로 올리는 개인용 도구입니다. YouTube Data API의 업로드 권한(youtube.upload) 하나만 사용하며, 운영자 한 사람의 계정에서만 쓰입니다. 다른 사용자를 위한 서비스가 아니며 가입이나 로그인 기능을 제공하지 않습니다.

horrorfactory is a personal tool that uploads short videos made by its owner to the owner's own YouTube channel as private videos. It uses only the YouTube Data API upload scope (youtube.upload) and is used solely with the owner's account. It is not offered to other users.
