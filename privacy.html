개인정보처리방침

horrorfactory · 시행일 2026년 9월 29일

1. 이 도구에 대하여

horrorfactory는 운영자 본인이 만든 영상을 운영자 본인의 YouTube 채널에 비공개로 올리는 개인용 도구입니다. 운영자 외의 사용자는 없습니다.

2. 사용하는 Google 권한

  • https://www.googleapis.com/auth/youtube.upload — 영상을 운영자 채널에 업로드하는 데에만 사용합니다.
  • 채널 목록, 시청 기록, 댓글, 구독자 정보 등 다른 YouTube·Google 데이터는 요청하지도 읽지도 않습니다.

3. 저장하는 정보

  • Google 로그인 후 발급되는 OAuth 토큰을 운영자 본인의 컴퓨터에만 저장합니다. 외부 서버로 보내지 않습니다.
  • 업로드 결과(영상 ID, 업로드 시각)를 같은 컴퓨터의 파일에 기록합니다.
  • 그 밖의 개인정보는 수집하지 않습니다.

4. 공유와 판매

어떤 정보도 제3자에게 공유하거나 판매하지 않으며, 광고에 사용하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회와 삭제

Google 계정 → 타사 앱 액세스에서 언제든 이 도구의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없으며, 운영자 컴퓨터의 토큰 파일을 지우면 모든 정보가 삭제됩니다.

6. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

Privacy Policy

horrorfactory · Effective September 29, 2026

About

horrorfactory is a personal tool that uploads videos made by its owner to the owner's own YouTube channel as private videos. It has no users other than the owner.

Google permissions

It requests only https://www.googleapis.com/auth/youtube.upload, used solely to upload videos. It does not request or read any other YouTube or Google data.

Data stored

The OAuth token issued after Google sign-in and a record of uploads (video ID, upload time) are stored only on the owner's computer and are never sent to any other server. No other personal data is collected.

Sharing

No data is shared with or sold to third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at Google Account → Third-party apps. Deleting the token file on the owner's computer removes all stored data.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service; the Google Privacy Policy applies.
